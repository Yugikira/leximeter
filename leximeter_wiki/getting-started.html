快速上手

从安装到跑通第一个结果，约 10 分钟。你只需要能打开一个命令行窗口。

第 1 步：安装

项目使用 Python（建议 3.11+）。推荐用 uv 管理环境，没有 uv 也可以用 pip：

# 进入项目目录（假设你已克隆或拿到项目文件夹）
cd leximeter

# 方式一：uv（推荐）
uv sync

# 方式二：传统 pip
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux
pip install -e .
pip install -e ".[embeddings]"  # 可选：本地嵌入（合并/去重的高级路径）

第 2 步：配置模型

Leximeter 本身不包含大模型，而是调用你配置的模型 API。在项目根目录复制 .env.example 为 .env 并按需填写：

# .env（将以下内容替换为你的模型服务配置）
LEXIMETER_PROTOCOL=chat                       # 协议：responses 或 chat
LEXIMETER_BASE_URL=https://api.deepseek.com   # 服务商地址
LEXIMETER_API_KEY=sk-你的密钥
LEXIMETER_MODEL=deepseek-chat                 # 默认模型名
你想用哪家模型填什么
DeepSeek协议 chat，地址 https://api.deepseek.com，模型例如 deepseek-chat
OpenAI协议 responses，只填 OPENAI_API_KEY 即可
MiniMax 或其他 OpenAI 兼容网关协议 chat，地址填网关的 base URL
本地模型（Ollama / vLLM）协议 chat，地址填本地端点（例如 http://localhost:11434/v1）

如果你计划大量使用 classify、rank 或 filter，还可以额外配置专用 Decision Provider（System One 协议，零输出 token 费用并直接返回校准概率）。未配置时，所有任务自动使用上面的 LLMClient：

# 可选：Decision Provider 配置（OpenRouter / AMD Radeon Token Factory / TypeSafe / vLLM）
LEXIMETER_DECISION_PROTOCOL=systemone
LEXIMETER_DECISION_BASE_URL=https://openrouter.ai/api
LEXIMETER_DECISION_API_KEY=sk-or-你的密钥
LEXIMETER_DECISION_MODEL=cloudflare/clef-flash
密钥安全与优先级 .env 已加入 .gitignore，不会提交到版本库。导入 leximeter 时自动加载 .env，但不会覆盖已存在的系统环境变量。也可以在终端临时传入环境变量，例如 PowerShell 中执行 $env:LEXIMETER_API_KEY="sk-..."。

第 3 步：写第一个脚本

把下面的内容存为 first_run.py，放在项目根目录：

import asyncio
import pandas as pd
import leximeter          # 导入时会自动读取 .env

async def main():
    # 你的数据：一列文本
    df = pd.DataFrame({"text": [
        "I heard that the new president instituted a law on gun control.",
        "My dog decided to eat food at 3am.",
        "Congress passes amended budget for 2026",
        "Scientists discover new species of frog in the Amazon rainforest.",
    ]})

    # 测量：每条文本在 3 个属性上打 0 到 100 分
    result = await leximeter.rate(
        df, "text",
        attributes={
            "discusses politics": "How much the text concerns political figures or issues (0-100).",
            "news headline": "How much the text reads like a journalistic headline (0-100).",
            "discusses animals": "How much the text mentions animals (0-100).",
        },
        save_dir="my_study/ratings",
        n_runs=2,               # 每条测 2 次取平均，结果更稳
    )
    print(result)

asyncio.run(main())

运行

uv run python first_run.py

你会看到类似下面的输出。由于模型不是确定性计算，每次运行的分数会有轻微差异：

第 4 步：保存与下一步

  1. 使用 result.to_csv("ratings.csv", index=False) 导出结果，供 Stata、R 或 Excel 分析。
  2. 所有中间产物和检查点保存在 my_study/ratings/ 目录中。断线或中断后重跑同一脚本会自动续跑，不会重复计费。
  3. 当 n_runs 大于 1 时，程序还会生成 ratings_full_disaggregated.csv，可直接用于计算信度指标如 ICC。
  4. 想尝试其他任务，可返回主页的任务列表查看每个功能的详细示例与参数说明。

常见问题

问题答案
这要花多少钱？取决于数据量与模型。v0.2.0 默认采用前缀固定提示词与 order_strategy="per_run"，在 DeepSeek 实测中缓存命中率达到 61.5% 到 86.7%，总费用可下降 23% 到 62%。以 DeepSeek 为例，1 万段文本测 1 个属性的成本通常只需几元到几十元。
结果可复现吗？同一段文本两次打分可能有正负 5 分内的波动。建议设 n_runs=2 或 3 取平均。检查点机制保证已完成的条目不会重复调用。
可以用自己的词表或量表吗？可以。所有属性、分类标签和编码类别都由你用自然语言定义，写清楚边界和锚点即可。
支持中文文本吗？支持。直接传入中文文本即可，attributes 和 labels 的定义也可以直接写中文。
断网或中途出错了怎么办？直接重跑同一脚本即可续跑。已完成的请求按检查点跳过；完整跑过的 discover、debias、ideate、poll、seed、codify 和 bucket 在输入不变时直接加载本地结果。更换模型、切换 Provider 或修改提示词配置时，过期检查点会自动失效并重算。想强制从头重跑，传入 reset_files=True。
