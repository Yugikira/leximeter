快速上手

从安装到跑通第一个结果，约 10 分钟。你只需要能打开一个命令行窗口。

第 1 步：安装

项目使用 Python（建议 3.11+）。推荐用 uv 管理环境，没有 uv 也可以用 pip：

# 进入项目目录（假设你已克隆或拿到项目文件夹）
cd leximeter

# 方式一：uv（推荐）
uv sync

# 方式二：传统 pip
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS / Linux
pip install -e .
pip install -e ".[embeddings]"  # 可选：本地嵌入（合并/去重的高级路径）

第 2 步：配置模型

Leximeter 本身不包含大模型——它调用你配置的模型 API。在项目根目录创建 .env 文件（模板见 .env.example）：

# .env —— 用你的服务商信息替换
LEXIMETER_PROTOCOL=responses          # 协议：responses 或 chat
LEXIMETER_BASE_URL=https://api.deepseek.com   # 服务商地址
LEXIMETER_API_KEY=sk-你的密钥
LEXIMETER_MODEL=deepseek-v4-flash     # 模型名
你想用哪家模型填什么
DeepSeek（性价比高，本指南示例默认）协议 chat 或 responses，地址 https://api.deepseek.com
OpenAI协议 responses，只填 OPENAI_API_KEY 即可
MiniMax / 其他 OpenAI 兼容网关协议 chat，地址填网关的 base URL
本地模型（Ollama / vLLM）协议 chat，地址填本地端点
密钥安全 .env 已被项目忽略（不进版本库）。也可以在命令行用环境变量临时传入，例如 PowerShell：$env:LEXIMETER_API_KEY="sk-..."。

第 3 步：写第一个脚本

把下面的内容存为 first_run.py，放在项目根目录：

import asyncio
import pandas as pd
import leximeter          # 导入时会自动读取 .env

async def main():
    # 你的数据：一列文本
    df = pd.DataFrame({"text": [
        "I heard that the new president instituted a law on gun control.",
        "My dog decided to eat food at 3am.",
        "Congress passes amended budget for 2026",
        "Scientists discover new species of frog in the Amazon rainforest.",
    ]})

    # 测量：每条文本在 5 个维度上打分 0-100
    result = await leximeter.rate(
        df, "text",
        attributes={
            "discusses politics": "How much the text concerns political figures or issues (0-100).",
            "news headline": "How much the text reads like a journalistic headline (0-100).",
            "discusses animals": "How much the text mentions animals (0-100).",
        },
        save_dir="my_study/ratings",
        n_runs=2,               # 每条测 2 次取平均，结果更稳
    )
    print(result)

asyncio.run(main())

运行

uv run python first_run.py

你会看到类似这样的输出（每次运行会略有不同——模型不是确定性计算）：

第 4 步：保存与下一步

  1. result.to_csv("ratings.csv", index=False) 导出，供 Stata / R / Excel 分析。
  2. 所有中间文件（原始模型回答、检查点）都在 my_study/ratings/ 目录里——断线或中断后重跑同一脚本会自动续跑，不重复花钱。
  3. 把 n_runs=2 的明细数据（ratings_full_disaggregated.csv）用于信度分析（如 ICC）。
  4. 想换任务？看主页的任务地图，每个功能都有独立页面（含示例代码与真实结果）。

常见问题

问题答案
这要花多少钱？取决于数据量与模型。以 DeepSeek 为例，1 万段文本 × 1 个属性的成本通常只有几元到几十元。API 有免费额度可先试。
结果可复现吗？同一段文本两次打分可能有 ±5 分内的波动。建议 n_runs=2~3 取平均；检查点机制保证"跑过的部分不重跑"。
可以用自己的词表/量表吗？可以。所有属性、分类标签、编码类别都是你定义的自由文本——写清楚定义就是你的测量工具。
中文文本支持吗？支持。所有提示词由模型处理，直接写中文文本即可；attributes 的定义也可以写中文。
断网/中断了怎么办？重跑同一脚本即可：已完成的条目按检查点跳过；完整跑过的复杂任务（discover / debias / ideate / poll / seed / codify）同输入重跑直接加载结果、零 provider 调用。想强制重跑传 reset_files=True。
