编码 codify

按你定义的类别，在每段文本中"逐字"标出属于该类的小片段——把质性研究中的人工编码交给大语言模型，拿回的是带原文位置的精确片段列表。

质性分析类LLM 核心

这是什么

社会科学里常见的做法是给访谈稿"编码"：划出提到某个主题的句子。codify 把这件事自动化，且保证片段是原文原词（程序在原文里逐字定位，而不是模型复述大意）。两种用法：

  • 静态模式（你给类别）：categories 给出类别与定义 → 输出每个类别一列，单元格是该类别在这段文本中找到的片段列表
  • 动态模式（让模型发现类别）：categories=None，只在 additional_instructions 里描述主题 → 模型自己发现类别，输出单列 coded_passages（类别名 → 片段列表）

长文本自动按词数分块；n_rounds > 1 时还会做"补全扫描"：把已标片段剔除后检查剩余文本，确保没有漏标的片段。

什么时候用 当你要统计"哪些句子属于哪些主题"以及它们在文本中的位置与数量时——比如给几十份访谈稿标出所有提到"工作压力"的句子。动态模式适合开放式编码：类别还没想清楚，先让模型从文本里发现。注意：只需给整段文本贴"是/否"标签用 分类；要抽取结构化信息（人名、机构、数字）用 抽取。

怎么用

三步：准备数据 → 定义类别（或只给主题）→ 调用。

import leximeter
import pandas as pd

# 1. 你的数据：一列"文本"
df = pd.DataFrame({"text": [
    "The product team shipped the dashboard late, but the quality held up.",
    "Funding ran dry and the startup froze all hiring.",
    "She praised the review process yet questioned the timeline.",
    "Quarterly targets were met; the board approved the expansion.",
]})

# 2. 类别定义（键 = 类别名，值 = 给模型的类别标准说明）
categories = {
    "positive sentiment":   "Positive or approving statements about work.",
    "resource constraints": "Mentions of limited money, staff, or time.",
}

# 3. 调用
result = await leximeter.codify(
    df, "text",
    categories=categories,
    save_dir="my_study/coding",
    model="deepseek-v4-flash",   # 或任何已配置的模型
)

动态模式把 categories 留空，在 additional_instructions 里描述主题（例如"标出所有提到工作压力的片段"），输出就是单列 coded_passages。

4 行 × 3 列：原列 + 每个类别一列。单元格是模型在该段文本中逐字定位到的原文片段列表；[] 表示该类别没有命中。片段由"开头 8 词 + 结尾 8 词"的逐字摘录定位而来，保证是原文原词。

回到数据里

静态模式返回"每类一列"，动态模式返回单列 coded_passages（每格是一个 {"类别名": [片段, …]} 字典）。每个片段都能在原文中回溯到确切位置，可以直接统计"哪个类别出现最多、分布在哪些文本里"。

实现原理（简版）

  1. 分块：超过 max_words_per_call 词的文本自动切块；类别超过 max_categories_per_call 个时分批。每个（行, 块, 类别批）是一个独立请求，并发执行、失败自动重试。
  2. 标记边界：模型对每个命中片段逐字输出"开头 8 词 + 结尾 8 词"作为边界（不足 20 词的片段整体写出），以 JSON 返回——这是为了能用程序精确定位。
  3. 逐字定位：word_matching 在原文中按"精确匹配 → 归一化匹配（忽略大小写/标点）→ 仅字母匹配 → 首/尾 20 字符兜底"逐级放宽的策略，把模型给的开头结尾摘录映射回原文的确切位置——即使模型记不准大小写或标点，也能找回原文原词。
  4. 补全扫描（n_rounds>1）：用分类器判断"剔除已标片段后的剩余文本是否还包含可编码内容"，只对仍被标记的类别在剩余文本上再编码一轮，循环直到没有新增。
  5. 输出：最终表写入 coded_passages.csv；开启 debug_print=True 时会打印每个类别的定位命中率，供你评估质量。

给模型的提示词（概括）

Codify 提示词结构（简化为要点） 扮演社会科学中的文本编码员。
类别："positive sentiment: Positive or approving statements about work." 等。
仔细通读全文，为每个属于某类别的片段标记边界：
逐字输出片段的开头 8 词与结尾 8 词（不足 20 词则整体写出）；
必须完全逐字一致（拼写、标点、大小写都不能变）；
同一段文字可同时标记到多个类别。输出 JSON。

提示词反复强调"逐字一致"和"从头到尾通读、不要漏标"——这是编码质量（覆盖率）的关键来源。

参数设置

参数默认值说明
categoriesNone类别字典：类别名 → 定义。给出时为静态模式（每类一列）；为 None 时进入动态模式（必须同时提供 additional_instructions）。
additional_instructions""额外指令；动态模式下用它描述要编码的主题（模型自行发现类别）。
column_name（必填）数据中文本所在列的列名。
save_dir（必填）保存中间产物与结果的目录（自动创建）。
modelgpt-5.4-mini使用的模型名；默认从环境变量 LEXIMETER_MODEL 读取。
n_parallels50同时发送给模型的请求数。API 允许时越高越快。
modality"text"文本类型提示："text"（段落）或 "entity"（短实体）。影响提示词措辞。
file_namecoding_results.csv原始编码响应的保存文件名；最终结果统一写 coded_passages.csv。
n_rounds2总轮数（含首轮）。1 = 不做补全扫描；大于 1 时执行"剔除已标片段 → 检查剩余 → 再编码"的补全循环。
max_words_per_call1000每次请求最多包含多少词。文本更长会自动切块。
max_categories_per_call8每次请求最多包含几个类别。类别很多时模型可能顾此失彼，设小一点更稳。
debug_printFalseTrue 时打印每个类别的片段定位命中率等调试信息。
completion_classifier_instructionsNone补全扫描中给分类器的追加指令（默认"仅在剩余文本仍有清晰可编码片段时返回 True"）。
reset_filesFalseTrue 时清空 save_dir 重新跑；False 时断点续跑（跳过已完成请求）。

完整参数与进阶选项见 ⚙️ 参数设置。
