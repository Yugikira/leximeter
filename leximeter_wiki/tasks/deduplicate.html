去重 deduplicate

把含义相同、写法各异的词全部映射到同一个"代表词"，得到一份干净的类别清单。

文本整理类LLM 核心

这是什么

自由回答和开放编码产生的原始词往往充满变体——同一个意思可以有几十种写法：

  • 拼写变体："AirPods"、"AirPodss"、"airpods"
  • 年份 / 版本后缀："AirPods 2026"、"AirPods 5G"、"AirPods 2.0"、"AirPods mkII"
  • 词性变化："Android"、"Androids"、"new Arduino"、"deluxe AirPods"

统计之前，这些变体应该归并成一个词——"AirPods 2026" 和 "AirPods 5G" 在你的类别表里应该算同一个东西。deduplicate 为每个等价词群选一个最精确、最具体的代表词，新增一列把每个词映射到它的代表词；没有重复的词原样保留。相当于请一位对领域很熟的整理员把同义词归到同一个词条下。

什么时候用 你想统计"哪些词出现过几次"，但原始列里同一个概念有大量写法变体；或者你想在 归桶 / 编码之前先把清单归一化。需要跨表连接两个数据源时用 合并 merge；需要按条件筛选行时用 过滤 filter。

怎么用

给一个 DataFrame 和列名，返回原表 + 一列 mapped_<列名>。

import leximeter
import pandas as pd

# 你的数据：一列"词"（可以有重复行）
df = pd.DataFrame({"tech": [
    "AirPods", "AirPods 2026", "AirPods 5G", "AirPodss",
    "AirPods 2.0", "AirPods mkII", "AirPods max", "AirPods ultra",
    "Android", "Androids", "Android 2026",
    "Arduino", "new Arduino",
]})

result = await leximeter.deduplicate(
    df, "tech",
    save_dir="my_study/dedup",
    model="deepseek-v4-flash",       # 或任何已配置的模型
)

回到数据里

新增的 mapped_tech 列与原文一一对应，行数不变——可以直接对代表词做频数统计（result["mapped_tech"].value_counts()）。模型的完整回答在 save_dir/deduplicate_responses.csv。

实现原理（简版）

一个难点：词很多时（几千上万个），一次塞给模型不现实。做法是"先分堆，再逐堆细查"：

  1. 预筛分组：当唯一词数 ≥ group_size 时，先把每个词换算成向量——想象成地图上的一个点，意思相近的词靠得近。聚类算法（kmeans2）把这些点分成若干堆，再切成不超过 group_size 条的一组。这样同义变体大概率落在同一组里，模型只需在小组内找重复，准确率高且每组的量可控。
  2. 逐组去重：每组发一个提示词，让模型穷尽找出所有"大体等价"的子集，并为每个子集指定一个代表词（必须是组内词，要求最精确、最具体）。输出 JSON：{"代表词": ["等价词", ...]}。
  3. 应用映射：把映射套回原列——命中的词替换成代表词，没命中的保持原样，得到 mapped_<列名> 列。

关闭 use_embeddings=False（或 embedding 服务不可用）时跳过聚类，直接按顺序切块，每块 group_size 条，走纯 LLM 路径——功能一样，只是同义变体可能被分到不同组而漏配。

给模型的提示词（概括）

Deduplicate 提示词结构（简化为要点） 以下是原始词清单。
穷尽找出所有"大体等价"的子集，每组选一个最精确、最具体的代表词（宁选具体的变体，不选笼统的大词）。
没有重复的词不要出现在输出里；词必须逐字照抄。
输出 JSON：{"代表词": ["等价词", ...]}；没有重复就输出空 JSON。

参数设置

参数默认值说明
save_dir（必填）保存中间产物与结果的目录（自动创建）。
modelgpt-5.4-mini使用的模型名；默认从环境变量 LEXIMETER_MODEL 读取。
n_parallels50同时发送给模型的请求数。API 允许时越高越快。
additional_instructionsNone追加给模型的任何额外指令（例如你认可的同义词规则）。
group_size500每组最多放多少条词。唯一词数达到该值时启用 embedding 聚类预筛。
modality"entity""entity"（短实体，如产品名）或 "text"（长文本段落；text 模式要求模型用标识键输出）。
use_embeddingsTrue是否用向量聚类做预筛分组；False 时按顺序切块（纯 LLM 路径）。
file_namededuplicate_responses.csv原始模型响应保存的文件名。
reset_filesFalseTrue 时清空 save_dir 重新跑；False 时断点续跑（embedding 缓存复用）。

完整参数与进阶选项见 ⚙️ 参数设置。
