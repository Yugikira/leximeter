理论生成 ideate

围绕一个主题，并行生成成百上千条结构化的新理论（或新点子），每条都自带标题、摘要、例子与可检验的预测。

生成类LLM 核心

这是什么

输入一个研究主题，输出 n_ideas 条互不相同的"思路报告"。每条报告固定六个部分：

  • Title：一个抓住核心的标题
  • In a nutshell：一句话核心
  • In one paragraph：一段摘要
  • Illustrative examples：现实例子
  • Testable predictions：可检验的预测
  • The full thinking：完整思考备忘（动机、文献、机制、验证设计）

scientific_theory=True（默认）时，要求模型按"前沿科学理论"的标准产出：新颖、具体、有独特预测、值得检验；设为 False 时改为"务实有用的好点子"，并给出可衡量的成功标准。

什么时候用 头脑风暴与假设生成：文献探索、理论梳理、研究问题还没定稿时批量获得候选。注意：ideate 产出的是候选理论，不是测量结果——拿到候选后，通常再用 评分 / 分类 打分筛选。如果只是要一批样本实体（人名、公司名），请用 样本生成 seed。

怎么用

一个主题、一个调用，其余交给模型。

import leximeter

result = await leximeter.ideate(
    topic="What explains the persistence of income inequality across generations?",
    n_ideas=5,             # 示例取 5 条便于展示
    save_dir="my_study/ideas",
    model="deepseek-v4-flash",
)

回到数据里

直接 result.to_csv("ideas.csv")。先看 title 与 nutshell 做一轮人工初筛，再把候选喂给 rate（如"新颖性""可行性"打分）或 classify 归类，即可把几百条候选压缩成可管理的备选清单。

实现原理（简版）

整个过程不需要你理解细节，但知道原理有助于判断结果质量：

  1. 生成提示词：把主题（与附加指令）填进模板，同一提示词复制 n_ideas 份——各份完全独立、互不影响，天然多样。
  2. 并行执行：批处理引擎把全部提示词并发发出（默认 50 路），原始报告边做边存（ideation_raw.csv），中断后断点续跑；完整跑过（ideate_state.json 输入签名匹配）则直接加载 ideation.csv，零 provider 调用。
  3. 六节解析：按 Title / In a nutshell / In one paragraph / Illustrative examples / Testable predictions / The full thinking 六个小标题逐行切分，各成一列；缺失的节留空。
  4. 输出：每行还带 idea_id（idea-00000 起）、topic 与原始报告 report_text，方便追溯。

给模型的提示词（概括）

Ideation 提示词结构（简化为要点） 你的任务是围绕以下主题提出理论：
[topic]
目标是提出一个真正新颖、推动领域前沿的科学理论；要具体、可检验、有别的理论预期不到的独特预测；宁可大胆，不可平庸。
写作要清楚易懂：专家能读、初学者也学得会。按六节输出：
Title: … / In a nutshell: … / In one paragraph: … / Illustrative examples: … / Testable predictions: … / The full thinking: …

scientific_theory=False 时，同样的结构，任务改为"提出一个务实有用的好点子"，预测节改为可衡量的成功信号。模板把"新颖性"与"可检验性"作为硬要求写进去——这就是候选理论质量的主要来源。

参数设置

参数默认值说明
topic（必填）研究主题或问题（如 "What explains the persistence of income inequality across generations?"）。
save_dir（必填）保存目录（自动创建）。
n_ideas1000生成的思路报告数量。
scientific_theoryTrueTrue 按"前沿科学理论"标准生成；False 按"务实可用的好点子"标准生成。
modelgpt-5.4-mini使用的模型；默认从环境变量 LEXIMETER_MODEL 读取。
n_parallels50同时发送给模型的请求数。
additional_instructionsNone追加给模型的任何指令（如理论取向、写作风格）。
file_nameideation.csv输出文件名。
reset_filesFalseTrue 时清空 save_dir 与 ideate_state.json 重新跑；False 时已完成验证——同主题同参数直接加载 ideation.csv，零 provider 调用（主题/参数变化自动全量重跑）。
max_retries0整个 run 失败时自动从检查点续跑的次数（重试强制 reset_files=False）。

完整参数与进阶选项见 ⚙️ 参数设置。
