抽取 extract

让大语言模型从每段文本里抽出结构化事实（公司名、年份、价格……），把散落在文字里的信息变成规整的数据表。

测量类LLM 核心

这是什么

你有一段段文本，其中已经含有你想要的信息，只是混在句子和叙述里。你想把每段文本的某些"字段"提取出来，变成一列列的规整数据。例如：

  • 从产品名里抽出生产公司、发布年份、单价
  • 从简历里抽出毕业院校、最近任职年份
  • 从学术摘要里抽出样本国家、数据来源年份

与 分类、评分 不同，extract 不判断"强弱"或"是不是"，而是把文本里已有的具体事实原样摘出来。一段文本通常对应一行；如果一段文本里含有多个实体（例如一份目录里列了多件商品），每个实体会各占一行。抽不到的信息记为空值。

什么时候用 当文本里有"现成的事实"需要变成表格字段时——数据库入库、做回归的协变量、把非结构化档案整理成编码表。需要测量"强弱程度"用 评分，需要"是不是"的判断用 分类。

怎么用

三步：准备数据 → 定义属性 → 调用。数据是一个表格（pandas DataFrame 或 CSV），其中一列是你的文本。

import leximeter
import pandas as pd

# 1. 你的数据：一列文本（这里是产品名）
df = pd.DataFrame({"product": ["Walkman", "iPad", "Nintendo Switch"]})

# 2. 定义要抽取的属性（键 = 字段名，值 = 给模型的抽取标准说明）
attributes = {
    "company":         "The company that made this product.",
    "year of release": "The year this product was first released.",
    "unit price":      "The typical unit price in USD.",
}

# 3. 调用
result = await leximeter.extract(
    df, "product",
    attributes=attributes,
    save_dir="my_study/extraction",
    model="deepseek-v4-flash",   # 或任何已配置的模型
    types={"year of release": "int", "unit price": "float"},  # 可选：把结果转成数值
)

回到数据里

返回的表格就是在你原来的表格上追加了每个属性一列。可以直接 result.to_csv("extracted.csv") 保存，再导入 Stata / R 分析。

实现原理（简版）

整个过程不需要你理解细节，但知道原理有助于判断结果质量：

  1. 生成提示词：对每段文本和全部属性（含抽取标准与格式规则），拼出一段标准指令（见下）。
  2. 并行执行：全部任务并发发送给模型（默认 50 路并行），失败自动重试，完成一批存一批。
  3. 解析：模型返回 JSON。若一段文本里含有多个实体，每个实体展开成独立的一行；抽不到的属性记 "unknown"（最终转成空值）。
  4. 聚合：如果 n_runs > 1（多次测量），每个字段取第一次成功抽到的值。
  5. 类型转换（可选）：types 参数把文本值转成数值或日期（如 "1979" → 1979），转不了的记录在日志里。

给模型的提示词（概括）

Extract 提示词结构（前缀固定，简化为要点） 请抽取以下属性并输出 JSON（每个实体一节）：{"实体名": {"属性名": "抽取到的值"}}。
格式规则：年份只给数字（如 "1979"，公元前用负数）、日期用 ISO 格式、价格不带货币符号；只给抽取到的数据本身，抽不到就写 "unknown"。
属性定义清单（静态前缀，固定在顶部以复用 KV 缓存）。
待抽取文本："…文本…"（动态内容放在末尾）。

属性定义里写清楚抽什么、按什么格式输出，模型就照此执行。定义越明确，抽取结果越一致。

参数设置

参数默认值说明
df必填你的数据表格（pandas DataFrame），须包含文本列。
column_name必填数据中文本所在列的列名。
attributes必填字典，键为字段名，值为抽取标准说明（含期望格式，例如年份只给数字）。
save_dir必填保存中间产物与结果的目录，不存在时自动创建。
modelgpt-5.4-mini使用的模型名，默认从环境变量 LEXIMETER_MODEL 读取。
n_runs1每段文本抽取几次。大于 1 时取第一次成功抽到的有效值，并额外保存逐次明细。
n_parallels50同时发送给模型的请求数。API 允许时越高越快。
n_attributes_per_runNone每次请求最多包含几个属性。属性较多时设小一点更稳。
additional_instructionsNone追加给模型的额外指令，例如补充格式要求。
modality"entity"文本类型提示，默认 "entity"（短实体，如产品名）；长段落可改为 "text"。
typesNone把结果列转为数值或日期，例如 {"year of release": "int", "unit price": "float"}，转换结果另存为 *_cleaned_coerced.csv。
order_strategy"per_run"属性键序策略："per_run"（同 run 固定以命中前缀缓存，跨 run 互异置换）、"fixed"（跨 run 固定）或 "per_item"（逐条随机打乱）。
file_name"extraction.csv"中间结果文件名，最终汇总文件为同名 *_cleaned.csv。
reset_filesFalseTrue 时清空检查点重新运行；False 时断点续跑，跳过已完成条目。
client / embedding_client / search_toolNone底层客户端，默认自动从环境变量配置。
**engine_kwargs无透传给底层批处理引擎或模型调用的额外参数，例如 max_output_tokens、temperature、timeout 与 warmup_first。

完整参数与进阶选项见 ⚙️ 参数设置。
