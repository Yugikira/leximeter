评分 rate

让大语言模型对每一段文本按你定义的属性打 0–100 分，得到一列可以直接分析的数值。

测量类LLM 核心

这是什么

你有一段段文本（访谈回答、新闻标题、产品名……），你想测量它们在某些"属性"上的强弱。例如：

  • 每条新闻标题的乐观程度、正式程度、愤怒程度
  • 每个食物的咸味、甜味
  • 每段公司评论的工作压力、对产品的信心

rate 对每段文本、每个属性给出一个 0–100 的分数。分数越高表示该属性越强。相当于请一位非常认真、从不出错的助理，按你写好的打分标准逐条评估。

什么时候用 当你的研究需要把文本变成"连续数值"时——回归的因变量、描述性统计的分组依据、跨组比较的指标。如果只需要"是/否"就用 分类，需要相对排序就用 排序。

怎么用

三步：准备数据 → 定义属性 → 调用。数据是一个表格（pandas DataFrame 或 CSV），其中一列是你的文本。

import leximeter
import pandas as pd

# 1. 你的数据：一列"文本"
df = pd.DataFrame({"entity": ["turkey", "pumpkin pie", "cornbread"]})

# 2. 定义要打分的属性（键 = 属性名，值 = 给模型的打分标准说明）
attributes = {
    "savory taste": "How savory the food tastes (0 = not at all, 100 = extremely).",
    "sweet taste":   "How sweet the food tastes (0 = not at all, 100 = extremely).",
}

# 3. 调用（保存位置 save_dir 会存下所有中间文件，方便检查与续跑）
result = await leximeter.rate(
    df, "entity",
    attributes=attributes,
    save_dir="my_study/ratings",
    model="deepseek-v4-flash",   # 或任何已配置的模型
)

回到数据里

返回的表格就是在你原来的表格上追加了每个属性一列。可以直接 result.to_csv("ratings.csv") 保存，再导入 Stata / R 分析。

实现原理（简版）

整个过程不需要你理解细节，但知道原理有助于判断结果质量：

  1. 生成提示词：对每段文本和每个属性，拼出一段标准指令（见下）。
  2. 并行执行：全部任务并发发送给模型（默认 50 路并行），失败自动重试，完成一批存一批。
  3. 解析：把模型的回答解析成数值（模型被要求输出 JSON）。
  4. 聚合：如果设置了 n_runs > 1（多次测量），每个属性取多次分数的平均值，降低随机波动。

给模型的提示词（概括）

Rate 提示词结构（前缀固定，简化为要点） 请按以下标准打分，输出 JSON：{"属性名": 0 到 100 的整数}。
打分锚点：0 表示完全不具备该属性，100 表示极其强烈；只依据文本内容判断，不要臆测。
属性定义清单（静态前缀，固定在顶部以复用 KV 缓存）。
待打分文本："…文本…"（动态内容放在末尾）。

每个属性后附上你写的标准说明（attributes 字典的值），模型据此校准分数含义。前缀固定布局配合默认 order_strategy="per_run"，在多条文本共享相同前缀时可显著提高服务端缓存命中率。

参数设置

参数默认值说明
attributes必填字典，键为属性名，值为打分标准说明。说明越具体，打分越一致。
column_name必填数据中文本所在列的列名。
save_dir必填保存中间产物与结果的目录，不存在时自动创建。
modelgpt-5.4-mini使用的模型名，默认从环境变量 LEXIMETER_MODEL 读取。
n_runs1每段文本测量几次。大于 1 时结果取平均，并额外保存逐次明细供信度分析使用。
n_parallels50同时发送给模型的请求数。API 允许时越高越快。
n_attributes_per_runNone每次请求最多包含几个属性。属性较多时设小一点更稳。
rating_scaleNone自定义评分量表说明，例如改为 1 到 7 分。
additional_instructionsNone追加给模型的额外指令。
modality"text"文本类型提示，可选 "text"（段落）或 "entity"（短实体，如食物、公司名）。
order_strategy"per_run"属性键序策略："per_run"（同 run 固定以命中前缀缓存，跨 run 互异置换抵消顺序锚定）、"fixed"（跨 run 固定以最大化热缓存）或 "per_item"（逐条随机打乱）。
reset_filesFalseTrue 时清空检查点重新运行；False 时断点续跑，跳过已完成条目。

完整参数与进阶选项见 ⚙️ 参数设置。
