任意提示词 whatever

不套模板，把你的提示词原样批量执行——并白拿现成的并发、断点续跑与（可选）联网检索。

生成类LLM 核心

这是什么

Leximeter 的每个正式任务（评分、分类、抽取……）都有一套固定模板和输出解析。但研究中总有"一次性"或"还没定型"的提问：

  • 试问几个开放问题，看看模型的回答像不像回事
  • 对一批文本各问一个自定义问题，结果只要原文即可
  • 探索阶段拿不准该用哪个正式任务

whatever 把你的提示词原样发给模型，批量执行后返回两列：Identifier（标识符）与 Response（回答原文）。可选 web_search=True：每条提示词先联网检索（Tavily）再作答，适合"需要最新信息"的问题。

什么时候用 临时探索、快速批量、研究设计未定型时。注意：whatever 不做解析、不做校验，返回的是模型原始文字——一旦问题与格式定型、需要可复现的测量，请改用 评分 / 分类 等有结构、有解析的任务。

怎么用

传一串提示词，或传一个表格（取其某一列逐行执行）。两种方式都支持。

import leximeter

result = await leximeter.whatever(
    prompts=[
        "Why do transformers outperform RNNs on long sequences?",
        "What is the main risk of training a model on a very small dataset?",
        "Give polite ways to tell someone their claim is incorrect.",
    ],
    save_dir="my_study/whatever",
    model="deepseek-v4-flash",
    web_search=False,   # True 时先联网检索（Tavily）再作答
)

回到数据里

result.to_csv("custom_responses.csv") 即可保存两列结果；json_mode=True 时返回还会多一列 Response JSON（解析后的字典），方便直接按字段读取。

实现原理（简版）

整个过程不需要你理解细节，但知道原理有助于判断结果质量：

  1. 整理提示词：字符串→单条；列表→逐条；表格→按 column_name 列逐行展开。每条配一个标识符（自己传，或自动用提示词的哈希）。
  2. 检索增强（可选）：web_search 开启（或给了 web_search_filters）时，每条提示词先调检索工具取回相关上下文，拼在提示词前再发送；检索失败或没有结果时原样发送——检索只增强、绝不丢弃任务。
  3. 批量执行：复用批处理引擎——并发发送（默认 50 路）、失败自动重试、完成一批写盘一批；中断后以 reset_files=False 续跑，不重复计费。
  4. 解析：默认直接返回模型原文；json_mode=True 时要求模型输出 JSON，并追加解析后的列。

给模型的提示词（概括）

Whatever 没有固定模板 你的提示词原样发送给模型。开启 web_search 后，实际发送的是：
[检索到的相关上下文]

[你的提示词原文]

所谓"增强"就是把检索到的资料放在提示词前面、当作背景材料——模型读到的仍是你的原话，只是多了可引用的信息。

参数设置

参数默认值说明
promptsNone提示词：一个字符串或字符串列表。与 df 二选一。
dfNone表格数据；提供时把 column_name 列的每一行当作一条提示词。
column_nameNonedf 中用作提示词的列名。
identifiersNone每条提示词的标识符列表（须与提示词数量一致）。
identifier_columnNonedf 中用作标识符的列名；缺省时自动用提示词哈希。
save_dir"whatever"保存目录（自动创建）。
modelgpt-5.4-mini使用的模型；默认从环境变量 LEXIMETER_MODEL 读取。
json_modeFalseTrue 时要求模型输出 JSON，并追加 Response JSON 列。
web_searchNone是否先联网检索再作答；None 时视 web_search_filters 是否提供而定。
web_search_filtersNone检索过滤条件（如时间范围、来源）；提供即自动开启检索。
search_context_size"medium"检索上下文规模：small / medium / large。
n_parallels50同时发送给模型的请求数。
file_namecustom_prompt_responses.csv输出文件名。
reset_filesFalseTrue 时清空 save_dir 重新跑；False 时断点续跑。

完整参数与进阶选项见 ⚙️ 参数设置。
