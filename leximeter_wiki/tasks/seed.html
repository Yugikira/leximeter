样本生成 seed

让大语言模型按你的说明，一批一批地生成互不重复的"代表性样本"（人、公司、主题……），并自动编号。

生成类LLM 核心

这是什么

研究里常常需要一大批样本：模拟访谈对象、创业公司、研究主题、政策案例……自己一条条写既慢又不全面。seed 用一段文字说明替代手工罗列：

  • 说清楚你想要什么样的实体（种类、分布、多样性要求）
  • 模型按说明逐批生成，每批默认 50 个
  • 每批都会把"已经生成过的样本"回传给模型，防止重复
  • 一直循环到凑满 num_entities 个，自动编号（entity-00000、entity-00001……）

输出是一个两列表格：entity（样本内容）+ entity_id（编号）。

什么时候用 当你需要大量互不重复、且有代表性的实体列表时——特别是作为 合成调查 poll 的人群种子。如果手头已有名单、只是想合并同类项，请用 去重 deduplicate；如果想要天马行空的新想法，用 理论生成 ideate。

怎么用

两步：写清楚实体说明 → 调用。说明写得越具体（种类、分布、多样性要求），生成越可控。

import leximeter

# 1. 写清楚你要什么样本
instructions = (
    "Representative startup founders building AI infrastructure "
    "companies: varied backgrounds, company focus, and geography."
)

# 2. 调用（示例取小批量便于展示）
result = await leximeter.seed(
    instructions,
    num_entities=8,              # 目标总数
    entities_per_generation=4,   # 每批生成几个
    save_dir="my_study/seeds",
    model="deepseek-v4-flash",
)

回到数据里

返回的是 entity / entity_id 两列，直接 result.to_csv("seeds.csv") 保存即可。这组实体可以接着喂给 poll（作为人群种子跳过第一阶段）、或作为 评分 / 分类 的测量对象。

实现原理（简版）

整个过程不需要你理解细节，但知道原理有助于判断结果质量：

  1. 生成提示词：把你的说明、每批数量、以及一批"已有样本"拼进模板。已有样本从已生成的实体中随机抽取，最多 existing_entities_cap 条——这就是防重复的关键。
  2. 循环生成：每批让模型用 JSON 返回一批新实体；解析成功后追加进总表，再进入下一批；如果某批模型没返回任何实体，说明"没货了"，停止。
  3. 生成预算：最多允许 ⌈num_entities ÷ entities_per_generation⌉ + 2 批。预算耗尽仍未凑满时，用已得到的实体收尾并打印提示——防止模型反复返回半截结果时无限循环。
  4. 编号与保存：截断到 num_entities 条，按 entity-00000 起编号，写入 seed_entities.csv。

给模型的提示词（概括）

Seed 提示词结构（简化为要点） 你的任务是按照以下说明生成 N 个实体：
[你的 instructions]
每条必须与其他条目互不相同；如果说明中给出分布，整体集合须忠实反映真实统计分布（不要高估少数群体）。
以下是已生成的实体样本，新实体不得与它们重复：
[随机抽取的已有样本]
以 JSON 输出，恰好 N 条：{"entity 1": "…", "entity 2": "…", …}

模板里特别强调"互斥性"与"忠实分布"：前者靠每批回传已有样本实现，后者靠明确指示模型按真实统计配比。这就是生成出来的实体"既有代表性、又不重复"的来源。

参数设置

参数默认值说明
instructions（必填）实体说明：种类、分布、多样性要求。越具体，生成越可控。
save_dir（必填）保存目录（自动创建）。
num_entities1000目标实体总数。达到即停止。
entities_per_generation50每批生成几个。越大调用次数越少，越小每批质量越稳。
existing_entities_cap100每批回传给模型"防重复"的已有样本上限（随机抽取）。
modelgpt-5.5使用的模型；默认从环境变量 LEXIMETER_MODEL 读取。
n_parallels50并发设置（本任务逐批串行执行，参数保留供引擎使用）。
deduplicateFalse是否对结果做附加去重（默认关闭）。
deduplicate_sample_seed42抽样已有实体样本的随机种子；固定后可复现同一批样本。
file_nameseed_entities.csv输出文件名。
existing_entitiesNone（调用时传）已有的实体列表；传入后从该基础上继续生成、避免重复。
reset_filesFalseTrue 时清空 save_dir 重新跑；False 时断点续跑。

完整参数与进阶选项见 ⚙️ 参数设置。
