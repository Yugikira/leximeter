参数设置

Leximeter 的每个功能都有大量参数，但 90% 的情况下你只需要改三样东西：你的数据、你的衡量标准（attributes/labels/categories）、保存位置（save_dir）。本页是全部参数的速查字典。

一、全局配置（环境变量 / .env 文件）

在项目根目录的 .env 文件中配置一次，所有任务共用。真实环境变量优先于 .env。

变量默认说明
LEXIMETER_PROTOCOLresponsesAPI 协议：responses（OpenAI Responses）或 chat（Chat Completions，DeepSeek/MiniMax/Ollama 通用）。
LEXIMETER_BASE_URL—服务商地址（如 https://api.deepseek.com）。
LEXIMETER_API_KEY—你的密钥；未设置时回退 OPENAI_API_KEY。
LEXIMETER_MODELgpt-5.4-mini默认模型名，代码里不指定 model= 时使用。
LEXIMETER_EMBEDDING_PROVIDERlocal嵌入 provider：local（本地 BGE 模型，需 [embeddings] 依赖）、openai（API）、none（禁用，任务自动降级为纯 LLM 路径）。
LEXIMETER_EMBEDDING_MODELBAAI/bge-m3嵌入模型名（openai provider 时例如 text-embedding-3-small）。
LEXIMETER_EMBEDDING_BASE_URL同 LLM 地址嵌入服务的独立端点（openai provider 用）。
LEXIMETER_EMBEDDING_API_KEY同 LLM 密钥嵌入服务的独立密钥（openai provider 用）。
LEXIMETER_SEARCH_PROVIDERnone联网搜索：tavily 或 none。需要 TAVILY_API_KEY。

二、所有任务共有的参数

参数默认说明
model环境变量或内置默认本次调用使用的模型名（可与全局不同，实现"混用多模型"）。
save_dir任务相关默认中间产物与结果的保存目录，自动创建。建议每个研究一个目录。
n_parallels50并发请求数。API 不限流时越大越快。
reset_filesFalseTrue = 清空 save_dir 从零重跑；False = 断点续跑（跳过已完成条目）。
client / embedding_client / search_toolNone高级：注入自定义 provider 实例（测试、本地模型、特殊网关时用）。

四、数据加载

函数参数
leximeter.load(folder_path)folder_path(必填, 文本文件夹) · save_name(None) · modality("text", 仅支持 text) · reset_files(False)。返回列：path / name / text。
参数调整的通用建议 先跑小样本（几十条）验证结果质量 → 再全量跑；成本敏感时降低 n_runs 或换更便宜的模型；结果波动大时提高 n_runs / 把属性定义写得更具体。
