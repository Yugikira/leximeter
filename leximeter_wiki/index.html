Leximeter

面向社会科学研究的纯文本测量工具。将访谈、演讲、评论、档案等定性文本转化为评分、分类、事实抽取和排序等定量数据。

这个指南是写给谁的 你不需要有深厚的编程背景。本指南假设你是一位社会科学研究者，手头有文字素材，希望用定量数据回答研究问题。只要跟着示例替换你的数据、衡量标准和保存目录，就能跑出一张可直接分析的表格。

Leximeter 能做什么？

如果你手头有一批访谈记录、新闻报道或政策文件，可以按研究问题选择对应任务：

你的问题用哪个功能得到什么
"每段话对某议题的支持度是多少？"评分 rate每段话 0 到 100 的连续评分
"这段话属于哪些类别？"分类 classify每段话一组是或否标记，可选校准概率
"这段提到了哪些事实，例如人名、年份或价格？"抽取 extract每段话一张结构化事实表
"哪些话更乐观，哪些更愤怒？"排序 rank两两比较拟合出的相对 z 分数与标准误
"两张表里的公司名是否指向同一家？"合并 merge模糊匹配的关联表
"哪些术语说的是同一个概念？"去重 deduplicate将等价术语映射到唯一代表词
"哪些条目符合某个条件？"过滤 filter保留标记与符合度得分
"怎样安全地分享这些访谈？"脱敏 deidentify用一致虚构信息替换敏感词后的文本
"把这段话改写成另一种风格？"改写 paraphrase改写后的文本与校验通过标记

"这些术语能分成几类？"归桶 bucket多轮投票生成的互斥分类法
"两段话有什么区别？"对比 compare差异属性与解释列表
"两类文本靠什么特征区分？"特征发现 discover判别特征与净占比汇总表

怎么工作的

Leximeter 的核心流程分三步：

  1. 构造统一任务。将每条文本与衡量标准组装成前缀固定的提示词，最大化服务端前缀缓存命中率，降低重复计费。
  2. 并发执行与断点续跑。调用你配置的大语言模型，或在 classify、rank、filter 等判断任务中使用专用 Decision Provider 并行评估，所有进度实时写入本地检查点。
  3. 整理为分析表格。评分取均值、分类取多数或校准概率、抽取展开为规范表格，导出 CSV 即可进入 Stata、R 或 Python 分析。
关于 AI 测量的说明 大语言模型测量不是确定性计算，同一段话测两次可能略有波动，可以通过多次重复运行取平均或多数决来降低噪声。对于有界判断类任务，也可以配置 System One 协议的 Decision Provider，在单次前向传播中直接获得校准概率且不产生输出 token 费用。Leximeter 的检查点与输入签名机制可确保中断后不重复计费，并在更换模型或修改标准时自动清理过期缓存。
